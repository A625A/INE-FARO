# Guía para Agentes de IA - INE-DATATON

Esta guía establece las normas de trabajo para agentes que colaboren en este repositorio.

1. **Estrategia de ramas**: Usar el formato `feature/ID-tarea` (ej. `feature/I-01-inventario`).
2. **Protocolo de commits**: Commits breves y descriptivos que incluyan el ID de la tarea.
3. **Flujo de trabajo**: Trabajar en una rama dedicada y solicitar integración (PR) a `main` al finalizar.
